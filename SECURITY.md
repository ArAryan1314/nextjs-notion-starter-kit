# Security Policy

This repository is a fork of [transitive-bullshit/nextjs-notion-starter-kit](https://github.com/transitive-bullshit/nextjs-notion-starter-kit).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/transitive-bullshit/nextjs-notion-starter-kit/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
